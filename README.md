# Laze Vapeshop — Business Analytics System

Laravel 12 (API + SQLite/MySQL) with a React + TypeScript front end (Vite, Recharts).
Final project: database program with descriptive, predictive and prescriptive business analytics.

## Requirements
PHP 8.2+, Composer, Node 18+.

## Setup
```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite      # Windows: type nul > database\database.sqlite
php artisan migrate --seed
npm install
npm run dev                          # terminal 1
php artisan serve                    # terminal 2 -> http://127.0.0.1:8000
```
Login: `admin@laze.test` / `password`

To use MySQL (XAMPP), set `DB_CONNECTION=mysql`, `DB_DATABASE=laze_vapeshop`, etc. in `.env`, create the database, then run `php artisan migrate:fresh --seed`.
For a production build run `npm run build`.

## Data (5 variables, 50+ records each)
Customers (60), Products (50), Suppliers (50), Campaigns (50), Sales (320). Generated by `database/seeders/DatabaseSeeder.php`.

## Features
- Login (token auth), full CRUD with search and paging for all five tables
- Dashboard with 7 charts and KPIs
- Analytics page: Descriptive → Predictive → Prescriptive, with an interactive marketing-budget optimizer
- Case study page (problem background, steps, connections)

## Where the analytics live
`app/Services/BusinessAnalytics.php` (the three steps), `app/Http/Controllers/AnalyticsController.php` (`GET /api/analytics?budget=50000`).
